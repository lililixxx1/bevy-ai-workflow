## 五、局限声明（④ 结论的边界；② 的对冲手段）

1. **同一模型重跑**：训练数据泄漏不可排除，④ 结论限定为「流程净室」口径。
2. **知情重跑**：注入资产含原任务结论本身（台账 T003/T004/T005 行、PIT-B-004、SKILL §6.1/6.2/6.4/6.5）——④ 的 0 返工是「资产携带原任务教训阻止其复发」命题预期效应的**直接演示**，不能称为无信息泄漏的独立复证（T004 尤甚：其原返工主因即 PIT-B-004 内容）。
3. **裁判与派发同会话**：复核全部以归档日志为准（三份裁判判定 + 独立复算 + 源码亲验落档可查）；且重跑侧复核为裁判验收级，与原任务侧 plan-code-reviewer 级独立审核的深度不完全等同。
4. **环境漂移**：subsecond 0.7.0-rc.0→0.7.10（semver 兼容）；T005 帧率数字与原证据不可直接对比。
5. **范围裁剪**（需求书逐条标注）：T003 裁测试集编写与两阶段机制叙述、T004 裁 bevy_brp_mcp 接入（环境不可执行）、T005 裁结论回写；断言自拟为已声明偏差。
6. **禁区遵约不可穷证**：以执行者自报 + 报告引用面核查（未见来自禁区的证据引用）。
7. ② 侧对冲：探针「凭记忆首试」的记忆污染面以时序合规对冲（失败原文先归档后查源码，逐轮留痕）；doctest 机器断言独立于作者声明（曾抓出两笔真发现与三处誊写笔误）。
